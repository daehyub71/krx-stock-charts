## 1. IA (정보구조도)

단일 화면 대시보드. 페이지 이동 없이 좌측에서 종목을 고르고 우측에서 읽는다.

```
시세판 (/)
├── 시황 테이프 (상단 고정)        KOSPI · KOSDAQ · KOSPI200 · USD/KRW
├── 헤더                          로고·서비스명 / 데이터 기준일 / 테마 전환
├── 좌측 레일 — 종목 선택
│   ├── 검색 (종목명·티커)
│   └── 종목 리스트 (종목명 · 티커 · 60일 스파크라인 · 전일 등락률)
└── 우측 메인 — 선택 종목
    ├── 종목 헤더 (종목명 · 티커 · 시장 · 업종 · 현재가 · 등락)
    ├── 컨트롤 바 (봉 주기 일/주/월 · 기간 3M/6M/1Y/3Y · 보기 차트/표)
    ├── 범례 (MA 현재값 · 상승/하락 · 봉 개수)
    ├── 차트 (캔들 + 거래량 + 이동평균 + 크로스헤어 툴팁)
    ├── 통계 타일 (기간 수익률 · 최고 · 최저 · 평균 거래량 · 연율 변동성)
    └── 시세 표 (보기=표일 때)
```

**설계 판단**: 종목 상세를 별도 라우트로 빼지 않고 한 화면에 둔다. 종목을 갈아타며 비교하는 것이 주 사용 패턴이라 화면 전환 비용이 그대로 사용성 손해가 되기 때문.

## 3. UI 디자인 시안

### 방향: "시황판을 종이 위에 옮긴 화면"

증권 단말의 검은 배경 대신 따뜻한 종이 톤을 바탕으로 쓴다. 화면을 하루 종일 들여다보는
트레이딩 도구가 아니라 **3년 흐름을 읽는 분석 도구**이므로, 자극적인 대비보다 오래 봐도
피로하지 않은 지면(紙面)의 인상을 택했다.

### 컬러 토큰

| 역할 | 라이트 | 다크 | 비고 |
|------|--------|------|------|
| 바탕 `--paper` | `#FAF9F5` | `#1B1A19` | |
| 카드 `--surface` | `#FFFEFB` | `#262624` | |
| 인셋 `--inset` | `#F1EFE7` | `#2F2E2B` | 검색창·타일 |
| 본문 `--ink` | `#1E1D1A` | `#F4F2EB` | |
| 보조 `--ink-2` / `--ink-3` | `#57544C` / `#8B8578` | `#B3AEA2` / `#857F74` | |
| 강조 `--accent` | `#C15F3C` | `#D97757` | **조작 요소 전용** |
| 상승 `--up` | `#C8372D` | `#E0655A` | 한국 증시 관행 (적색 상승) |
| 하락 `--down` | `#2E6FBF` | `#5A9BE8` | 한국 증시 관행 (청색 하락) |
| MA1~4 | `#A87F1C` `#0E96AE` `#8A5AD0` `#B0435E` | `#B58C2E` `#2AA0B8` `#9770DE` `#CC5A78` | 아래 검증 통과 |

**강조색과 의미색의 분리**: 테라코타 강조색은 활성 탭·포커스 링·선택된 종목 등 *조작 요소*에만 쓴다.
데이터의 의미(상승/하락)는 적·청으로만 전달해, "주황색은 조작, 빨강/파랑은 시세"라는 규칙이 화면 전체에서 유지된다.

**색각 검증**: 이동평균 4색은 `validate_palette.js`로 **전체 쌍(all-pairs)** 검사를 라이트·다크 각각 통과했다
(밝기 대역 / 채도 하한 / CVD 분리 / 정상시각 분리 / 대비 5개 항목 PASS). 눈대중이 아니라 스크립트로 확정한 값이다.

### 타이포그래피

| 역할 | 지정 |
|------|------|
| UI·본문 | 시스템 한글 산세 스택 (`Pretendard` → `Apple SD Gothic Neo` → `Noto Sans KR`) |
| **모든 숫자** | 고정폭(`ui-monospace` 계열) + `font-variant-numeric: tabular-nums` |
| 라벨(eyebrow) | 10px / 600 / `letter-spacing .11em` / 대문자 |

숫자 전부에 고정폭·자릿수 정렬을 건 것이 이 디자인의 핵심 결정이다. 시세·축·툴팁·표의 자릿수가
세로로 정확히 맞아, 값을 읽지 않고 **자릿수 길이만으로 크기를 비교**할 수 있다.

> 웹폰트를 링크하지 않는다 — Artifact CSP가 폰트 CDN을 차단하고, 한글 폰트는 data URI로 인라인하기엔 용량이 크다.
> 실제 Next.js 구현에서는 `next/font/local`로 Pretendard subset을 셀프 호스팅한다.

### 차트 규격

- **캔들**: 몸통 `slot-2px`(간격 2px 확보), 최대 22px, 꼬리 1px, 모서리 반경 최대 1.5px
- **거래량**: 같은 x 슬롯, 상승/하락색 20% 불투명도
- **이동평균**: 1.6px, 일봉 5/20/60/120 · 주봉 5/20/60 · 월봉 3/12 (주기별로 다르게)
- **격자**: 가로선만, `--rule-2` (배경에 가깝게 후퇴)
- **최종가**: 우측 축에 색상 pill + 점선 수평선
- **크로스헤어**: 세로 점선 + 해당 봉 2px 외곽선 + 툴팁(시·고·저·종·등락률·거래량)
- **접근성**: 차트가 `tabindex=0`, ←/→ 방향키로 봉 이동 · `표` 보기로 동일 데이터 표 제공 · 색만으로 정보를 전달하지 않음(범례 + 값 병기)

### 마이크로 인터랙션

과하지 않게 3가지만 둔다 — 종목 행 hover 배경, 툴팁 페이드(100ms), 탭 전환 시 즉시 재계산.
`prefers-reduced-motion`에서 전부 정지한다.

## 4. 시안이 검증한 설계 결정

목업은 그림이 아니라 **동작하는 목업**이라, SPEC의 미확정 항목을 실제로 검증했다.

| 항목 | 검증 내용 | 확정 결과 |
|------|-----------|-----------|
| 리샘플 규칙 | 일봉 782개 → 주봉 157 / 월봉 37. 월봉의 시가·고가·종가·거래량합이 해당 월 일봉과 일치함을 스크립트로 확인 | 규칙 자체는 검증됨. 계산 **위치**는 D4로 파이프라인 확정 |
| D3 (차트 라이브러리) | 외부 라이브러리 없이 SVG로도 캔들·거래량·MA·크로스헤어가 구현 가능함을 확인 | **lightweight-charts 채택** (D3 확정) — 시안의 SVG 구현은 시각 기준으로만 사용 |
| MA 워밍업 | 표시 구간 앞에 MA 최장주기만큼 워밍업 데이터를 붙여야 첫 봉부터 MA선이 그려짐 | **조회 로직의 요구사항**으로 확정. D4 변경과 무관하게 유효 |

> **D2·D4 변경 반영 (2026-08-15)**: 주봉/월봉이 파이프라인에서 사전 계산되어 Supabase `ksc_bars`에
> `timeframe`으로 구분 저장되므로, 프론트는 선택된 주기를 조회해 lightweight-charts에 전달한다.
> 화면 동작·레이아웃은 시안과 동일하며 데이터 출처만 바뀐다.

## 5. 합의 사항 — ✅ 확정 (2026-08-15)

| # | 항목 | 확정 내용 | 근거 |
|---|------|-----------|------|
| A | 전체 톤 | ✅ **따뜻한 종이 톤** (라이트 기본, 다크 대응) | 증권 단말형 다크 대신 채택. 3년 흐름을 읽는 분석 도구라 오래 봐도 피로하지 않은 지면 인상을 택함 |
| B | 상승/하락 색 | ✅ **적색 상승 · 청색 하락** (한국 증시 관행) | 글로벌 관행(녹색 상승)이 아닌 국내 사용자 기준 |
| C | 레이아웃 | ✅ **좌측 종목 레일 + 우측 차트, 단일 화면** | 종목을 갈아타며 비교하는 것이 주 사용 패턴이라 화면 전환 비용이 그대로 사용성 손해가 됨 |
| D | 차트 구현 | ✅ **lightweight-charts** (SPEC D3) | 시안의 SVG 자체 구현은 시각 기준으로만 사용 |
| E | 통계 타일 구성 | 🔶 **시안안 기본 채택** — 기간 수익률 · 최고가 · 최저가 · 평균 거래량 · 연율 변동성 | A·B·C가 모두 시안대로 확정되어 같은 기준을 적용. **M4 착수 전까지 항목 교체·추가 가능** |

> **M4(차트) 착수 조건 충족.** A~D가 확정되었고 E는 시안안을 기본값으로 진행한다.
> E를 바꾸려면 이 표를 먼저 고치고 M4 태스크에 반영한다.

### 확정에 따라 고정되는 것

- `docs/mockups/dashboard.html`의 **컬러 토큰·타이포·레이아웃이 구현 기준**이 된다 (§3).
- lightweight-charts에는 §3의 토큰을 주입해 시안과 같은 색으로 그린다 — 라이브러리 기본 테마를 쓰지 않는다.
- 이동평균 4색은 색각 검증을 통과한 값이므로 **임의 변경 시 재검증**이 필요하다.
